# Active-Directory-Project
A majority of organizations are using Active Directory to manage resources such as users, computers, and groups.
In this project I set up my own Active Directory environment to learn more about IT administration and about how a domain works. 
This project will also be beneficial for the blue team. We will also have our own Splunk instance.
That will record events from the Windows server that has active directory and our target machine.
At the end we will use a VM with Kali Linux and perform a brute force attack to see what
Kind of telemetry that generates which in the future could be useful to create alerts, dashboards, and reports.
